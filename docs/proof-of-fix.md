# Proof of Fix

## Specification

A **Proof of Fix** is the flagship artifact generated by VulnSeal. It serves as cryptographic proof that:
1. A deterministic vulnerability existed and was reproduced.
2. An authorized human operator signed off on a minimal code patch.
3. The patch was applied in an isolated digital twin.
4. The exact original security check was replayed and now passes cleanly.
5. All regression tests passed, proving no functional regression occurred.
6. An independent verification agent signed the verdict.
